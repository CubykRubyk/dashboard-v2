# Sécurité

Ne publiez jamais de mot de passe, de clé Dolibarr, de sauvegarde de base de
données ou de fichier `.env` dans le dépôt.

Les vulnérabilités ne doivent pas être signalées dans une issue publique.
Contactez directement l’administrateur du projet avec une description du
problème et les étapes minimales permettant de le reproduire.
